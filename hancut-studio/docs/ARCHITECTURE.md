# HanCut Studio 구조

## 구성

- `model`: 직렬화 가능한 프로젝트, 미디어, 클립, 자막, 출력 설정
- `service/MediaProbeService`: ffprobe를 통한 길이·해상도·오디오 스트림 분석
- `service/FramePreviewService`: FFmpeg 프레임 추출 또는 Java2D 생성 장면 미리보기
- `service/FfmpegExportService`: 모든 장면을 동일 규격 H.264/AAC로 정규화하고 결합한 뒤 SRT를 번인
- `service/SceneGenerator`: 한국어 문장 경계를 이용한 오프라인 대본→장면 생성
- `ui`: Swing 기반 미디어함, 플레이헤드, 순차 타임라인, 속성·자막·출력 패널

## 프로젝트와 렌더링

`.hancut` 파일은 Java 객체 직렬화 형식이며 원본 미디어 자체를 복사하지 않고 절대 경로를 참조한다. 프로젝트를 다른 PC로 옮길 때는 원본 파일 경로도 맞춰야 한다.

내보내기는 임시 폴더에서 클립별 MP4를 만든다. 해상도·FPS·픽셀 형식·오디오 샘플레이트를 통일하므로 서로 다른 영상과 이미지도 연결할 수 있다. 마지막 단계에서 전역 자막이 있으면 SRT 필터로 영상에 새긴다. 완료 또는 실패 후 임시 파일은 삭제한다.

## 보안·개인정보

기본 기능은 로컬에서 동작하며 프로젝트나 미디어를 서버로 전송하지 않는다. 외부 프로세스 호출은 인자 배열을 사용하는 `ProcessBuilder`로 실행해 셸 명령 삽입을 피한다.
